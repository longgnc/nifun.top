# QingNing Platform

> A full-featured personal gaming homepage — home page + mini games + handy tools + music player

- Website: [nifun.top](https://nifun.top)
- Repository: https://github.com/longgnc/nifun.top
- Built with Vue 3 + Vite, Docker-ready

## Features

### Home

- [x] Loading animation
- [x] Site intro (with a hidden easter egg)
- [x] Hitokoto quote
- [x] Date & time display
- [x] Real-time weather (Amap API, with a free fallback chain via open-meteo / wttr.in when no key is set)
- [x] Time progress bars (today / week / month / year)
- [x] Random background images + particle effects
- [x] Mobile friendly / PWA support

### Toy Box

| Module | Contents |
| --- | --- |
| Mini games | 2048, Minesweeper, Snake, Solitaire, Gomoku |
| Tools | Calculator, Unit converter, World clock, Linux command cheatsheet |
| Others | Forum, Music, Movies, Books, Website navigation |

### Music Player

- Floating player based on Aplayer
- Supports both a local playlist (`src/assets/musicList.json`, generated by script) and online playlists via Meting API

## Quick Start

> Requires Node.js > 16.16.0

```bash
npm install -g pnpm
pnpm install
pnpm dev      # local preview
pnpm build    # build to dist/
```

## Configuration

Copy `.env.example` to `.env` and adjust as needed:

```bash
VITE_SITE_NAME = "青柠平台"        # site name
VITE_SITE_AUTHOR = "青柠"          # author
VITE_SITE_URL = "nifun.top"        # site URL

# Weather key (Amap Web Service key; leave empty to use the free fallback APIs)
VITE_WEATHER_KEY = ""

# Site launch date, YYYY-MM-DD (used by the time capsule; leave empty to disable)
VITE_SITE_START = "2020-10-24"

# ICP license number (leave empty to hide)
VITE_SITE_ICP = ""

# Online playlist (Meting API)
VITE_SONG_API = "https://api.wuenci.com/meting/api/"
VITE_SONG_SERVER = "netease"       # netease / tencent
VITE_SONG_TYPE = "playlist"
VITE_SONG_ID = "9379831714"        # leave empty to disable
```

### Custom Content

| Content | Location |
| --- | --- |
| Site links (navigation) | `src/assets/siteLinks.json` |
| Social links | `src/assets/socialLinks.json` |
| Local playlist | `src/assets/musicList.json` (run `node scripts/generateMusicList.cjs` after changing `public/Music/`) |
| Background images | `public/images/background*.jpg` |
| Site icons | `public/images/icon/` |

> Note: `public/Music/` and `*.mp3` are excluded via `.gitignore`; music files are not tracked by git.

## Docker Deployment

```bash
# Option 1: Docker
docker build -t nifun-top .
docker run -p 12445:12445 -d nifun-top

# Option 2: docker-compose
docker-compose up -d
```

Then visit `http://localhost:12445`. You can also upload the `dist` directory to any static server, or deploy with platforms like Vercel.
